## Review Cadence

Review performance after meaningful checkpoints such as:
- ~24 hours
- ~72 hours
- ~7 days

## Batch Review Questions

After each 5–10 posts, answer:
1. Which hook pattern holds attention best?
2. Which content pillar creates the most shares?
3. Which topics generate saves?
4. Which posts convert views into follows?
5. Which joke/meme structures work repeatedly?
6. Which edits create retention drops?
7. Which formats are too expensive or slow to produce?
8. What should be increased, decreased, or stopped in the next batch?
