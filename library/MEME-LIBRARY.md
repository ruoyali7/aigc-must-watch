# Meme Library

This is a semantic index, not a dump of copyrighted clips. Store links, descriptions, rights notes, and alternatives.

## Categories

### New Challenger / Dramatic Entrance
Use when a new model/company enters a rivalry.

### Comeback
Use when a company/model recovers after falling behind.

### Rivalry / Fight
Use for competitive releases, benchmark battles, pricing wars, or creator tool comparisons.

### Fail / Disaster
Use for broken demos, outages, obvious model failure, or overpromising.

### Skeptical Reaction
Use when a launch claim deserves caution.

### Copycat / Everyone Doing the Same Thing
Use for product convergence or obvious imitation.

### Victory / Celebration
Use for a genuine breakthrough or surprising win.

### Money / Funding / Valuation
Use for huge funding rounds, spending, market moves, or absurd cost scales.

### Job Replacement / Workplace
Use for agents, automation, coding assistants, or labor stories.

### WTF / Absurdity
Use when the underlying event is already inherently strange.
