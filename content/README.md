# Content Workflow

Use this folder for individual post records.

Recommended naming:

- `candidates/YYYY-MM-DD-short-slug.md`
- `in-production/YYYY-MM-DD-short-slug.md`
- `published/YYYY-MM-DD-short-slug.md`

A post starts from the relevant template in `templates/`, moves through the SOP in `POST-SOP.md`, and ends with analytics appended after publishing.

Do not store large raw video assets in this repository unless there is a deliberate Git LFS/media-storage plan. Keep source URLs and local/cloud asset references in the post record instead.
